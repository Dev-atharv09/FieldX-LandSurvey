 FieldX — Offline Land Survey & Parcel Verification App

FieldX is an offline-capable mobile application designed to simplify field surveys, parcel verification, and digital land inspection.

It enables field officers to collect land information, capture photographs, mark parcel boundaries, and synchronize collected data when internet connectivity becomes available.

 Our Features

- GPS & Location
  
  - Locate land parcels using GPS.
  - View parcel location on a map.

- Parcel Boundary Mapping
  
  - Draw and mark parcel boundaries using polygons.
  - Record surveyed land areas digitally.

- Land Details
  
  - Survey/Khasra number
  - Owner details
  - Land area
  - Parcel status

-  Field Photography
  
  - Capture photographs during inspection.
  - Associate photos with the relevant parcel.

- Offline Mode
  
  - Continue surveying without an active internet connection.
  - Store field data locally.


-  Parcel Verification
  
  - Verified
  - Mismatch
  - Pending

-  Digital Inspection Report
  
  - Generate a structured digital record after completing an inspection.

Problem Statement

Traditional field-based land inspection can involve manual paperwork, inconsistent data collection, connectivity limitations, and difficulty maintaining accurate digital records.

FieldX aims to provide a mobile-first digital workflow that allows field officers to perform parcel surveys even in areas with limited or no internet connectivity.

 Why FieldX?

FieldX focuses on combining:

- Offline-first field data collection
- GPS-based parcel identification
- Digital boundary mapping
- Photographic evidence
- Parcel verification
- Automatic synchronization

into a single mobile workflow.
